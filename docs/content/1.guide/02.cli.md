## Two commands and a server

```bash
npx @agntn/curves compute log --a 2 --b 2 --p 17 --point '{"x":"5","y":"1"}' --other '{"x":"16","y":"4"}'
```

```text
{"operation":"log","order":"19","scalar":"13"}
```

That one line is exactly what a model reads. Want it pretty? Add `--json`.

From here on it's plain `curves`. In a project that means `pnpm exec curves`. Or `pnpm add -g @agntn/curves` once.

| Command | Does |
| --- | --- |
| `curves compute <operation>` | add, double, negate, multiply, check, order, count, points, log on a curve you give |
| `curves secp256k1 <operation>` | add, subtract, negate, multiply, lift, check on secp256k1 |
| `curves mcp` | the MCP server over stdio |

Where do the flags come from? From the tool schemas, the same ones MCP lists. The CLI is `runCli` from [`@agntn/tools`](https://tools.agntn.dev/guide/cli), so a new argument shows up here without anyone writing it twice.

## Points and numbers

`compute` takes a point as JSON, the very object the tool gets. A bit more typing than `5,1`, sure. But it's the same shape everywhere. Integers are decimal or `0x` hex. Negative a? `--a -3` works, and so does `--a=-3`. It's reduced mod p anyway.

```bash
curves compute multiply --a 2 --b 2 --p 17 --point '{"x":"5","y":"1"}' --scalar -2 --json
```

```text
{
  "operation": "multiply",
  "point": {
    "x": "6",
    "y": "14"
  }
}
```

`secp256k1` takes SEC1 hex, compressed or not. `--no-compressed` writes 65 bytes instead of 33.

```bash
curves secp256k1 lift --x 79be667ef9dcbbac55a06295ce870b07029bfcdb2dce28d959f2815b16f81798
```

## When it says no

A refusal is one line on stderr and exit code 1. No stack trace.

```bash
curves secp256k1 subtract --point 0279be667ef9dcbbac55a06295ce870b07029bfcdb2dce28d959f2815b16f81798 --other 0279be667ef9dcbbac55a06295ce870b07029bfcdb2dce28d959f2815b16f81798
```

```text
The result is the point at infinity, which is no public key, as with P minus P
```

An option the operation doesn't take is refused too. `count` with a `--scalar`? It says so instead of quietly ignoring it. A typo like `--nmae` gets the list of flags the command does take. `curves <command> --help` lists them with their descriptions.
